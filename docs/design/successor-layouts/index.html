PaneForge · successor layout alternatives

Three interactive prototypes, one sample task, same content and identity. Fictional work and messages; no agent, provider or Taskdriver connection. Evaluation strip at the bottom of each page counts actions, wrong turns and recoveries for the shared five-step task.

A

Left navigation

Chat / Work / Code live in the sidebar above projects and saved chats, like the current studio demo. Search box top right.

  • Everything reachable from one column
  • Costs sidebar width; modes and projects compete
B

Top mode control

A centred Chat / Work / Code segmented control in the title bar; the sidebar holds only projects and saved chats.

  • Modes read as "where am I"; sidebar stays about content
  • Mode switch leaves the project list untouched
C

Task-first

No global mode. One list of projects with their tasks and chats; the selected task carries Conversation / Result / Code tabs. ⌘K finds anything.

  • Code is never far from the task it belongs to
  • Cross-project "what needs me" view is a task, not a mode
