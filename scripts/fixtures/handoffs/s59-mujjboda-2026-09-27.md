## Gotchas
- compute-guard denies any Bash command whose TEXT contains a test/typecheck invocation (even `cat >> file` + a test run in one call, or an ack reason string mentioning them) as a "full run": split file edits and test runs into separate calls; single test files run fine locally alone.
- compute-guard holds Simulator/Maestro work while load >20 or memory pressure 2 (Simulator boot spiked load to 159; flows.cjs Chrome pushes memory pressure to 2): run flows before booting the Simulator, or wait with bg-wait `--sim-ready`.
- Foreground `until ...; sleep` is denied; `lsof -p <pid> +r 5` blocks until a process exits without a sleep loop (macOS has no pwait).
- zsh: `echo ===` fails (=cmd expansion) - quote it.
- Metro logs `[first-load]` lines; harness bundle URL `http://localhost:8081/tests/app-harness.tsx.bundle?platform=ios&dev=true&minify=false&tap=...` works for native tap checks with synthetic data (no sign-in needed).
